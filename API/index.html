API Reference

Module containing models representing patients and their data.

The Model layer is responsible for the 'business logic' part of the software.

Patients' data is held in an inflammation table (2D array) where each row contains inflammation data for a single patient taken over a number of days and each column represents a single day across all patients.

daily_max(data)

Calculate the daily maximum of a 2D inflammation data array for each day.

:param data: A 2D data array with inflammation data (each row contains measurements for a single patient across all days). :returns: An array of max values of measurements for each day.

def daily_max(data):
    """Calculate the daily maximum of a 2D inflammation data array for each day.

    :param data: A 2D data array with inflammation data (each row contains measurements
    for a single patient across all days).
    :returns: An array of max values of measurements for each day.
    """
    return np.max(data, axis=0)

def load_csv(filename):
    """Load a Numpy array from csv

        Parameters
        ----------
        filename : str
            path to the csv file

        Returns
        -------
        np.ndarray
            2D array of inflammation data
    """
    return np.loadtxt(fname=filename, delimiter=',')
